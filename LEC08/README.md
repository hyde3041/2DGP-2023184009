# Drill #8 · Animation Viewer

제출 브랜치: `drill-08-animation-viewer`

## 구현 기준

- `LEC08/animation_viewer.py`에서 걷기, 달리기, 점프, 공격을 순서대로 재생한다.
- 각 동작을 정확히 5회 재생한 후 마지막 프레임에서 1초 정지한다.
- 공격의 정지가 끝나면 걷기로 돌아가 무한 반복한다.
- 800×600 화면 중앙 영역에서 캐릭터를 화면 높이의 절반 이상으로 확대한다.
- 동작마다 자연스러운 속도를 지정하고, 정지 중에도 ESC와 창 닫기가 작동한다.
- 크기가 서로 다른 프레임 사각형과 동작별 서로 다른 프레임 개수를 지원한다.

## 개발 기록

부모 커밋이 없는 빈 브랜치에서 과제 파일만 20개 커밋으로 개발했다.
각 커밋은 실제 기능·수정·검증 단위로 나누어 한국어로 작업 내용을 설명한다.
스프라이트 좌표 검증 → 재생 시간/횟수 → 확대/정렬 → 실제 SDL 렌더링 순으로 확인했다.

## 실행

Python과 `pico2d`가 필요하다. 설치 및 실행:

```powershell
python -m pip install -r LEC08/requirements.txt
python LEC08/animation_viewer.py
```

`ESC` 또는 창의 닫기 버튼으로 종료한다.
파일 경로는 소스 파일을 기준으로 찾으므로 다른 폴더에서 절대 경로로 실행해도 된다.

## 재생 설정

| 순서 | 동작 | 프레임 수 | 속도 | 5회 재생 + 정지 |
| --- | --- | --- | --- | --- |
| 1 | 걷기 | 8 | 8 FPS | 5초 + 1초 |
| 2 | 달리기 | 8 | 12 FPS | 약 3.33초 + 1초 |
| 3 | 점프 | 6 | 6 FPS | 5초 + 1초 |
| 4 | 공격 | 6 | 8 FPS | 3.75초 + 1초 |

전체 한 순환은 약 21.08초이다. 화면 갱신은 최대 약 60Hz이고, 애니메이션 시간은
`perf_counter()` 경과시간으로 따로 계산한다. 5번째 반복의 마지막 프레임에도
정상 프레임 시간을 부여한 뒤 1초 더 유지한다.

화면 왼쪽에서 현재 동작, 반복 횟수, 프레임 번호, FPS, 정지 남은 시간을 확인할 수 있다.

## 가산점 구현 — 제출 시 함께 언급

1. **프레임별 크기가 다른 복잡한 시트 지원:** `knight_frames.json`의 각 프레임에
   `rect: [x, top, width, height]`를 개별 기록했다. 동일 동작 안에서도 폭과 높이가
   다르며, 균등 격자로 잘라내지 않는다. 예: 점프 1프레임은 123×169,
   4프레임은 151×234이다. 이미지 좌상단 좌표를 Pico2D 좌하단 좌표로 변환한다.
2. **동작별 서로 다른 프레임 개수 지원:** 걷기/달리기 각 8개, 점프/공격 각 6개로,
   현재 동작의 `len(frames)`를 사용해 반복 종료를 판단한다.

`pivot`은 원본 시트 좌표의 캐릭터 기준점이다. 그림을 자르는 사각형이 달라져도
몸통 위치와 점프 궤적을 유지한다. 가로세로에 동일 배율을 적용해 비율을 보존하고,
동작 도중 프레임마다 확대 배율을 바꾸지 않는다. 화면 높이 600px 대비 캐릭터가
최소 약 324px 이상 보이도록 원본 시트 2배, 공격 시트 1.8배를 적용했다.

## 검증

```powershell
python -B -m unittest discover -s LEC08 -p test_animation_viewer.py -v
python -B LEC08/verify_viewer.py --screenshots LEC08/.verification
python -B LEC08/verify_viewer.py --escape
python -B LEC08/verify_viewer.py --live --escape
```

- 12개 자동 검사: 정확한 5회 재생, 마지막 프레임 유지, 1초 정지 경계,
  3바퀴 순환, 불규칙 경과시간, 확대 비율/화면 경계, 종료 입력, 잘못된 이미지 크기.
- 실제 SDL 검사: 가짜 이미지 객체 대신 실제 PNG/JPEG를 로드하고 main을 실행한다.
  두 번째 걷기의 1초 정지 구간에서 창 닫기 또는 ESC로 종료한다.
- `--live`는 실제 창에서 약 26초간 정상 속도로 재생한다.
  기본 모드는 창 없이 시간을 가속하지만 실제 SDL 렌더링은 수행한다.
- `--screenshots`로 저장한 28개 화면은 로컬 검증 자료이며 Git에 포함하지 않는다.
- 검증 환경: Python 3.14, Pico2D 1.5.1, Windows.
